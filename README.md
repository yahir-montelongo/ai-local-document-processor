# AI Document Intelligence API

Microservicio backend desarrollado en **Python** y **FastAPI** diseñado para la integración de modelos de Inteligencia Artificial con sistemas empresariales, permitiendo el análisis automatizado y consultas sobre documentos de texto.

## Stack Tecnológico
* **Backend:** Python, FastAPI
* **Contenedorización:** Docker, Docker Compose
* **Base de Datos:** SQL (SQLAlchemy)
* **Arquitectura:** REST APIs, Principios SOLID, Inyección de Dependencias
